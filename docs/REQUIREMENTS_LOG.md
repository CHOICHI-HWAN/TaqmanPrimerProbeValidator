| 항목 | 내용 |
|---|---|
| 이전 결과 백업 폴더(`LASV/results_v0.19.0_pre_idrefactor_backup`) 삭제 여부 | 결과 동일성은 확인됨. 삭제하려면 지시 필요 |

| 이전 폴더(`pipeline_snakemake`)와 데모 패키지(`pipeline_snakemake_demo`) | v0.19.0의 변경을 반영하지 않음 |
| 다른 바이러스 워크플로(Nipah, Ebola, Monkeypox, CCHF) | entry 페이지만 있고 각 워크플로는 아직 없음 |
| conda/mamba 공개 패키지(taqmanvalidator) | 라이선스 점검까지만 했고 공개 업로드는 하지 않음 |
| 파이프라인 이름(Genome Hacker 등) | 제안만 했고 확정되지 않음 |
